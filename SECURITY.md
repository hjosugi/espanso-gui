# Security Policy

[English](SECURITY.md) | [日本語](SECURITY.ja.md)

## Supported versions

Until 1.0, only the latest release receives security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for `hjosugi/espanso-gui` when available. Otherwise, open an issue that contains no exploit details and asks the maintainer to establish a private channel.

Do not report Espanso GUI vulnerabilities to the Espanso project. Espanso GUI is independent and its maintainers are solely responsible for this application.

Please include the affected version, operating system, reproduction outline, impact, and any suggested mitigation. Never include real snippet content, credentials, or private configuration files.
