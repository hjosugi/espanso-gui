# Espanso GUI 0.1.0

[English](v0.1.0.md) | [日本語](../ja/releases/v0.1.0.md)

The first public preview delivers a complete Rust-native visual workspace for Espanso 2 match files.

## Highlights

- Create and search snippets without hand-writing YAML.
- Edit plain text, Markdown, HTML, images, and forms.
- Build date, clipboard, choice, random, fixed, shell, script, form, and global variables with guided controls.
- Insert variables into content with one click.
- Detect duplicate triggers and undefined variables before saving.
- Protect configuration with conflict detection, automatic backup, atomic writes, and recoverable deletion.
- Import and export CSV, create complete configuration snapshots, and manage the local Espanso process.

## Platform notes

The initial preview artifacts are expected to be unsigned. Windows SmartScreen and macOS Gatekeeper may display warnings. Verify downloaded artifacts against the checksums attached to the release.

## Independence notice

Espanso GUI is unofficial and independent. Please report all problems in `hjosugi/espanso-gui`; do not contact the Espanso project about this application.
