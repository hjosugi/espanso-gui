# Espanso GUI 0.4.0

[English](v0.4.0.md) | [日本語](../ja/releases/v0.4.0.md)

This release puts the native accessibility API under automated test on all
three platforms and fixes the defect that audit found, without claiming that the
human screen-reader audit is complete.

## Highlights

- Add `scripts/native-accessibility-audit.py`, which launches the optimized
  build against a disposable copy of the audit fixture and drives it only
  through keyboard input and the platform accessibility API: AT-SPI on Linux,
  UI Automation on Windows, and the AX API on macOS. In Japanese and English it
  records every primary view, walks the complete Tab order, checks the search
  shortcut, switches language through accessibility actions, and checks modal
  focus containment and Escape in the Add snippet file dialog.
- Run that audit in CI on Ubuntu, Windows, and macOS after the release build,
  covering both the wide and the compact layout, and upload its reports as
  artifacts.
- Stop advertising focus and click actions on unavailable buttons. AccessKit's
  AT-SPI adapter reports push buttons as enabled regardless of their disabled
  flag, so Orca offered unavailable Espanso service, backup, CSV,
  file-deletion, and Save buttons as ordinary focusable controls that Tab then
  skipped.
- Include the dependency maintenance recorded under 0.3.2 in the changelog:
  `rustls` 0.23.45 for
  [RUSTSEC-2026-0285](https://rustsec.org/advisories/RUSTSEC-2026-0285), the
  yanked `chacha20` 0.10.1 replaced with 0.10.2, and compatible egui 0.36.2,
  `indexmap` 2.14.2, and `open` 5.4.4 updates.

## Verification scope

The final source passes formatting, Clippy with warnings denied, the complete
107-test suite on Linux, Windows, and macOS, locked optimized release builds,
the `cargo-deny` policy, and the native accessibility-API audit on all three
platforms.

Issue #9 remains open. The automated audit reads the same API that Narrator,
VoiceOver, and Orca use, but it does not listen to speech, and it is not a
`Pass` row in the audit record. AT-SPI still reports disabled push buttons as
enabled; that needs an AccessKit change. Issue #6 is unchanged; without signing
credentials the Windows and macOS artifacts are reported as unsigned.

## Independence notice

Espanso GUI is unofficial and independent. Please report all problems in
`hjosugi/espanso-gui`; do not contact the Espanso project about this application.
