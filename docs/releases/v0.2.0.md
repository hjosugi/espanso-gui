# Espanso GUI 0.2.0

This release makes structured editing safer, adds visual app-specific profiles,
and improves rich content, conflict recovery, accessibility, and packaging.

## Highlights

- Preserve every unchanged YAML byte during structured edits, including comments,
  anchors, block scalars, quoting, and unknown fields.
- Create and edit app-specific `config/*.yml` profiles with visual filters,
  injection options, delays, shortcuts, and form sizing.
- Resolve simultaneous local and on-disk changes with a local three-way merge,
  per-field choices, persistent history, and safe restoration.
- Compose portable HTML for emphasis, headings, links, lists, colors, and local
  images while retaining direct source editing. Preview never executes scripts or
  downloads remote content.
- Navigate by keyboard, switch between Japanese and English, scale the UI from
  80% to 200%, and use improved accessible labeling.
- Build with optional Windows Authenticode signing and macOS Developer ID
  signing/notarization. The workflow records the actual status below.

## Data-safety note

An edited YAML fragment may be reformatted, but unrelated content is preserved
byte for byte. Every overwrite and restoration first records the latest on-disk
file in local history.

## Independence notice

Espanso GUI is unofficial and independent. Please report all problems in
`hjosugi/espanso-gui`; do not contact the Espanso project about this application.
