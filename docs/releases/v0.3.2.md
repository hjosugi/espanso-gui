# Espanso GUI 0.3.2

[English](v0.3.2.md) | [日本語](../ja/releases/v0.3.2.md)

This maintenance release restores the repository dependency policy after a new
`rustls` advisory and a yanked `chacha20` release, and picks up compatible
upstream bug fixes. It contains no application feature changes and no
configuration-format changes.

## Highlights

- Update `rustls` from 0.23.43 to 0.23.45 for
  [RUSTSEC-2026-0285](https://rustsec.org/advisories/RUSTSEC-2026-0285): TLS 1.3
  handshake messages were accepted across encryption-level boundaries.
  `rustls` is used by the HTTP image loader that `egui_extras` provides.
- Replace the yanked `chacha20` 0.10.1 with 0.10.2, a transitive dependency of
  the atomic configuration writer.
- Update `eframe`, `egui_extras`, and the rest of the egui family from 0.36.1 to
  0.36.2. Upstream fixes include case-insensitive image file extensions and a
  hit-test panic on NaN widget bounds.
- Update `indexmap` from 2.14.0 to 2.14.2.
- Update `open` from 5.4.1 to 5.4.4, which is used to open the documentation
  and the configuration folder. Upstream fixes opening Windows paths whose
  parent directories contain PowerShell wildcard characters such as `[` and `]`,
  and no longer leaves zombie launcher processes on macOS and other Unix
  systems.

## Verification scope

The final source passes formatting, Clippy with warnings denied, the complete
103-test suite, a locked optimized release build, and all configured
`cargo-deny` advisory, ban, license, and source checks.

Issues #6 and #9 are unchanged by this release.

## Independence notice

Espanso GUI is unofficial and independent. Please report all problems in
`hjosugi/espanso-gui`; do not contact the Espanso project about this application.
