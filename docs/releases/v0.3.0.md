# Espanso GUI 0.3.0

[English](v0.3.0.md) | [日本語](../ja/releases/v0.3.0.md)

This release completes the broad Japanese and English interface pass, makes the
native GUI more usable with keyboards, screen readers, high scaling, and narrow
viewports, and separates major presentation concerns into focused Rust modules.

## Highlights

- Search snippets across every loaded match file, filter by Espanso-native
  `search_terms`, and persist YAML-order, name, or trigger sorting without
  modifying user configuration.
- Use a consistent, contrast-tested light, dark, or system theme; four readable
  type roles; persistent scroll bars; large shared controls; responsive compact
  navigation; and scroll-safe dialogs from 80% through 200% app scale.
- Expose named controls, headings, selected states, live status announcements,
  contextual row actions, and structurally owned modal content through AccessKit.
  Automated bilingual tree and input tests cover all primary views and all eight
  dialog states.
- Localize the complete snippet, profile, variable, form, diagnostics, settings,
  history, onboarding, feedback, and dialog experience in Japanese and English,
  together with public documentation and repository contribution surfaces.
- Preserve quoted `#` values, block scalars, CRLF, missing final line endings,
  unknown form-field types, and unrelated YAML bytes. Backup snapshots now reject
  destinations inside the active configuration tree and avoid timestamp
  collisions.
- Split navigation, top bar, preferences, settings, snippet/profile/variable
  editors, library projection, shared controls, HTML composition, and Raw YAML
  highlighting into focused Rust modules with typed actions and fewer UI-side
  effects.
- Restrict package jobs to read-only repository access and strengthen Windows and
  macOS signing checks for artifact identity, timestamps, hardened runtime,
  Gatekeeper, notarization tickets, and disk-image integrity.

## Verification scope

The final source passes formatting, Clippy with warnings denied, and the complete
102-test suite. That suite covers release-workflow structure and extensive
AccessKit trees, responsive bounds, localization, YAML preservation, conflict
handling, and storage safety on the shared implementation.

Repository signing credentials are not configured, so this release is expected
to publish explicitly unsigned Windows and macOS artifacts. The credential-backed
signing paths remain gated on a future genuine signed release. The recorded native
accessibility audit also still requires complete human passes with Windows
Narrator, macOS VoiceOver, and Linux Orca; the Linux diagnostic work is evidence,
not a completed platform row.

## Data-safety note

An intentionally edited YAML fragment may be reformatted, but unrelated content
is preserved byte for byte. Every overwrite and restoration first records the
latest on-disk file in local history.

## Independence notice

Espanso GUI is unofficial and independent. Please report all problems in
`hjosugi/espanso-gui`; do not contact the Espanso project about this application.
