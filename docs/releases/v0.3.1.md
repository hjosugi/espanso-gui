# Espanso GUI 0.3.1

[English](v0.3.1.md) | [日本語](../ja/releases/v0.3.1.md)

This maintenance release makes dependency policy and the remaining native
accessibility audit reproducible without claiming that the human audit is
complete.

## Highlights

- Add one canonical disposable audit fixture covering plain, Markdown, HTML,
  image, form, regular-expression, and multi-trigger matches; every supported
  local and global variable kind; default and app-specific profiles; deliberate
  diagnostics; and forward-compatible unknown YAML values.
- Load that fixture through the production storage layer in the test suite and
  verify that an intentional edit preserves unknown file, match, profile, and
  form-field data.
- Document identical English and Japanese preparation, merge-conflict setup,
  reset, scaling, localization, and screen-reader flows for native auditors.
- Enforce repository dependency policy in CI with `cargo-deny`, covering known
  advisories, yanked and unsound crates, licenses, wildcard dependencies, and
  package sources.
- Refresh Rust 1.95-compatible transitive dependencies and remove stale
  version-specific wording from public maintenance surfaces.

## Verification scope

The final source passes formatting, Clippy with warnings denied, the complete
103-test suite, a locked optimized release build, and all configured
`cargo-deny` advisory, ban, license, and source checks.

Issue #9 remains open: automated evidence and the Linux diagnostic passes do
not replace complete human end-to-end audits with Windows Narrator, macOS
VoiceOver, and Linux Orca. Issue #6 is intentionally unchanged; when signing
credentials are absent, the release workflow reports Windows and macOS
artifacts as unsigned instead of implying that they were signed.

## Data-safety note

Use only a copied fixture during the native audit. An intentionally edited YAML
fragment may be reformatted, but unrelated and unknown content is preserved,
and normal application writes retain a recoverable backup.

## Independence notice

Espanso GUI is unofficial and independent. Please report all problems in
`hjosugi/espanso-gui`; do not contact the Espanso project about this application.
