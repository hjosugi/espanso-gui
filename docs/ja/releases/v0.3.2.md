# Espanso GUI 0.3.2

[English](../../releases/v0.3.2.md) | [日本語](v0.3.2.md)

このmaintenance releaseでは、新しい`rustls` advisoryとyankされた`chacha20` releaseによって
失敗していたrepository dependency policyを復旧し、互換性のあるupstreamの不具合修正を
取り込みます。アプリの機能変更と設定形式の変更はありません。

## 主な変更

- [RUSTSEC-2026-0285](https://rustsec.org/advisories/RUSTSEC-2026-0285)（TLS 1.3の
  handshake messageがencryption levelの境界をまたいで受理される問題）に対応するため、
  `rustls`を0.23.43から0.23.45へ更新。`rustls`は`egui_extras`のHTTP image loaderで
  使用されています。
- yankされた`chacha20` 0.10.1を0.10.2へ置き換え。atomicな設定書き込みが間接的に依存する
  crateです。
- `eframe`、`egui_extras`、その他のegui関連crateを0.36.1から0.36.2へ更新。upstreamの
  修正には、image file拡張子の大文字小文字を区別しない判定や、widget boundsがNaNの場合の
  hit-test panic修正が含まれます。
- `indexmap`を2.14.0から2.14.2へ更新。
- documentationと設定folderを開く際に使用する`open`を5.4.1から5.4.4へ更新。upstreamでは、
  親directory名に`[`や`]`などのPowerShell wildcard文字を含むWindows pathを開けない問題と、
  macOSなどのUnix系でlauncher processがzombieとして残る問題が修正されています。

## 検証範囲

最終sourceはformat、警告を拒否するClippy、全103 test、locked optimized release build、
設定済みの`cargo-deny` advisory／ban／license／source checkをすべて通過しています。

Issue #6と#9は本releaseでは変更していません。

## 独立性に関する注意

Espanso GUIは独立した非公式プロジェクトです。問題はすべて`hjosugi/espanso-gui`へ報告し、
本アプリについてEspansoプロジェクトへ連絡しないでください。
