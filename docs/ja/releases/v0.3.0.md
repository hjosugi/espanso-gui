# Espanso GUI 0.3.0

[English](../../releases/v0.3.0.md) | [日本語](v0.3.0.md)

このリリースでは日英UIの広範な対応を完了し、キーボード、スクリーンリーダー、高い拡大率、狭い表示領域でnative GUIを使いやすくするとともに、主要な表示処理を目的別のRust moduleへ分離しました。

## 主な変更

- 読み込み済みの全match fileを横断するsnippet検索、Espanso標準の`search_terms`による絞り込み、ユーザー設定を書き換えないYAML順／名前順／trigger順の保存可能な並べ替えを追加。
- contrast検証済みのlight／dark／system theme、4種類の読みやすい文字体系、常時表示scroll bar、大きな共通操作部、responsive compact navigation、80～200%表示に対応するscroll可能なdialogを追加。
- 名前付き操作部、見出し、選択状態、live status announcement、対象名付き行操作、構造的に所有されるmodal contentをAccessKitへ公開。全主要画面と8種類すべてのdialog stateを日英の自動tree／input testで検証。
- snippet、profile、variable、form、diagnostics、settings、history、onboarding、操作結果、dialogの全体と、公開文書／repository contribution surfaceを日本語／英語対応。
- 引用値内の`#`、block scalar、CRLF、末尾改行なし、未知form-field type、無関係なYAML byteを保持。使用中の設定tree内へのbackupを拒否し、同一timestamp時のsnapshot衝突も回避。
- navigation、top bar、preferences、settings、snippet／profile／variable editor、library projection、共通control、HTML composition、Raw YAML highlightingを、型付きactionと少ないUI副作用を備える目的別Rust moduleへ分離。
- package jobのrepository権限をread-onlyへ制限し、Windows／macOS署名についてartifact identity、timestamp、hardened runtime、Gatekeeper、notarization ticket、disk-image integrityの検証を強化。

## 検証範囲

最終sourceはformat、警告を拒否するClippy、全102 testを通過しています。testはrelease workflow構造のほか、共有実装上の広範なAccessKit tree、responsive bounds、localization、YAML保持、競合処理、storage safetyを検証します。

repositoryの署名credentialは未設定のため、このreleaseではWindows／macOS artifactが明示的な未署名として公開される予定です。credentialを使う署名経路の最終確認には、将来の実際の署名releaseが必要です。記録済みnative accessibility auditにも、Windows Narrator、macOS VoiceOver、Linux Orcaを人が操作する完全な確認が残っています。Linuxのdiagnostic作業は証拠であり、platform行の完了ではありません。

## データ安全性に関する注意

意図的に編集したYAML断片は書式変更される場合がありますが、無関係な内容はバイト単位で保持されます。上書き／復元前にはディスク上の最新版をlocal historyへ必ず記録します。

## 独立性に関する注意

Espanso GUIは独立した非公式プロジェクトです。問題はすべて`hjosugi/espanso-gui`へ報告し、本アプリについてEspansoプロジェクトへ連絡しないでください。
