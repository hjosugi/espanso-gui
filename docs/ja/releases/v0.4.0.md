# Espanso GUI 0.4.0

[English](../../releases/v0.4.0.md) | [日本語](v0.4.0.md)

このreleaseでは、人によるscreen reader監査の完了を主張せず、3つのplatformすべてでnative
accessibility APIを自動testの対象にし、その監査で見つかった不具合を修正します。

## 主な変更

- `scripts/native-accessibility-audit.py`を追加。最適化buildを監査fixtureの破棄可能なcopyに
  対して起動し、keyboard入力とplatformのaccessibility API（LinuxのAT-SPI、WindowsのUI
  Automation、macOSのAX API）だけで操作します。日本語と英語で全主要画面を記録し、Tab順全体を
  巡回し、検索shortcutを確認し、accessibility actionで言語を切り替え、「スニペットファイルを
  追加」dialogでmodal内のfocus封じ込めとEscを確認します。
- その監査をrelease buildの後にUbuntu、Windows、macOSのCIで実行し、wide／compactの両layoutを
  確認して、reportをartifactとしてupload。
- 利用できないbuttonがfocus／click actionを公開しないよう修正。AccessKitのAT-SPI adapterは
  disabled flagにかかわらずpush buttonを有効として報告するため、Orcaは利用できないEspanso
  service、backup、CSV、file削除、保存のbuttonを、Tabでは到達しない通常のfocus可能なcontrol
  として提示していました。
- 変更履歴の0.3.2に記録したdependency maintenanceを含みます。
  [RUSTSEC-2026-0285](https://rustsec.org/advisories/RUSTSEC-2026-0285)に対応する`rustls`
  0.23.45、yankedになった`chacha20` 0.10.1から0.10.2への置き換え、互換性のあるegui 0.36.2、
  `indexmap` 2.14.2、`open` 5.4.4への更新です。

## 検証範囲

最終sourceはformat、警告を拒否するClippy、Linux／Windows／macOSでの全107 test、locked
optimized release build、`cargo-deny` policy、3 platformでのnative accessibility API監査を
すべて通過しています。

Issue #9はopenのままです。自動監査はNarrator、VoiceOver、Orcaと同じAPIを読みますが、音声は
聞いておらず、監査記録の`Pass`行にはなりません。AT-SPIではdisabledなpush buttonが引き続き
有効として報告されます。これはAccessKit側の変更が必要です。Issue #6は変更していません。署名
credentialがない場合、Windows／macOS artifactは未署名として報告されます。

## 独立性に関する注意

Espanso GUIは独立した非公式プロジェクトです。問題はすべて`hjosugi/espanso-gui`へ報告し、
本アプリについてEspansoプロジェクトへ連絡しないでください。
