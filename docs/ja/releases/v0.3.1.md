# Espanso GUI 0.3.1

[English](../../releases/v0.3.1.md) | [日本語](v0.3.1.md)

このmaintenance releaseでは、人手監査の完了を主張せず、dependency policyと残るnative
accessibility監査を再現可能にします。

## 主な変更

- plain、Markdown、HTML、image、form、regular-expression、multi-trigger match、
  対応する全local／global variable種類、default／app-specific profile、意図的な
  diagnostic、将来互換の未知YAML値を含む、破棄可能な標準監査fixtureを追加。
- production storage layerでfixtureを読み込むtestを追加し、意図した編集後も未知のfile、
  match、profile、form-field dataが保持されることを検証。
- native監査者が同じ条件で実行できるよう、準備、merge-conflict発生、reset、拡大表示、
  localization、screen-reader flowを日英の手順書へ記載。
- 既知advisory、yanked／unsound crate、license、wildcard dependency、package sourceを
  対象に、`cargo-deny`でrepository dependency policyをCIへ適用。
- Rust 1.95互換のtransitive dependencyを更新し、公開maintenance surfaceに残っていた
  version固定表現を修正。

## 検証範囲

最終sourceはformat、警告を拒否するClippy、全103 test、locked optimized release build、
設定済みの`cargo-deny` advisory／ban／license／source checkをすべて通過しています。

Issue #9はopenのままです。自動化された証拠とLinux diagnostic passは、Windows Narrator、
macOS VoiceOver、Linux Orcaを人が操作する完全なend-to-end監査を代替しません。Issue #6は
意図的に変更していません。署名credentialがない場合、release workflowは署名済みと誤認させず、
Windows／macOS artifactを未署名として報告します。

## データ安全性に関する注意

native監査ではfixtureのcopyだけを使用してください。意図的に編集したYAML断片は書式変更される
場合がありますが、無関係な内容と未知の内容は保持され、通常のapp書き込みでは復元可能なbackupを
残します。

## 独立性に関する注意

Espanso GUIは独立した非公式プロジェクトです。問題はすべて`hjosugi/espanso-gui`へ報告し、
本アプリについてEspansoプロジェクトへ連絡しないでください。
