# Espanso GUI 0.1.0

[English](../../releases/v0.1.0.md) | [日本語](v0.1.0.md)

最初の公開previewでは、Espanso 2のmatch fileを扱う完全なRust native visual workspaceを提供します。

## 主な機能

- YAMLを手書きせずsnippetを作成、検索。
- plain text、Markdown、HTML、image、formを編集。
- date、clipboard、choice、random、fixed、shell、script、form、global variableをguided controlで作成。
- 1回の操作でvariableをcontentへ挿入。
- 保存前にduplicate triggerとundefined variableを検出。
- conflict detection、automatic backup、atomic write、recoverable deletionで設定を保護。
- CSV入出力、設定全体のsnapshot、local Espanso process操作。

## プラットフォームに関する注意

最初のpreview artifactは未署名の予定です。Windows SmartScreenとmacOS Gatekeeperが警告を表示する場合があります。downloadしたartifactをrelease添付のchecksumと照合してください。

## 独立性に関する注意

Espanso GUIは独立した非公式プロジェクトです。問題はすべて`hjosugi/espanso-gui`へ報告し、本アプリについてEspansoプロジェクトへ連絡しないでください。
