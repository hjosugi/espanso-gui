# Espanso GUI 0.2.0

[English](../../releases/v0.2.0.md) | [日本語](v0.2.0.md)

このリリースでは構造化編集の安全性を高め、アプリ別設定画面を追加し、リッチコンテンツ、競合からの復元、アクセシビリティ、パッケージ作成を改善します。

## 主な変更

- コメント、アンカー、ブロックスカラー、引用形式、未知のフィールドを含む、変更していないYAMLの全バイトを構造化編集で保持。
- 視覚的なフィルター、注入設定、遅延、ショートカット、フォームサイズを使って、アプリ別`config/*.yml`プロファイルを作成／編集。
- ローカル3方向マージ、項目単位の選択、永続履歴、安全な復元により、編集中とディスク上で同時に行われた変更を解決。
- ソースの直接編集を残しつつ、強調、見出し、リンク、リスト、色、ローカル画像向けの移植可能なHTMLを作成。プレビューはスクリプトを実行せず、外部コンテンツを取得しません。
- キーボード操作、日本語／英語切替、32／24／20／18ポイントの4段階文字体系、40×48ポイントの操作部、16×12ポイントの内側余白、常時表示スクロールバー、80～200%で自動調整するUI、高コントラストなRaw YAML色分け、改善されたアクセシブルラベル。
- 常時見えるチェック印付き操作部で通常／正規表現トリガーを選択可能にし、方式切替を直ちに保存して既存トリガー文字列を失わないよう修正。
- 任意のWindows Authenticode署名とmacOS Developer ID署名／公証。ワークフローは実際の状態を下に記録します。

## データ安全性に関する注意

編集したYAML断片は書式変更される場合がありますが、無関係な内容はバイト単位で保持されます。上書き／復元前には、ディスク上の最新版をローカル履歴へ必ず記録します。

## 独立性に関する注意

Espanso GUIは独立した非公式プロジェクトです。問題はすべて`hjosugi/espanso-gui`へ報告し、本アプリについてEspansoプロジェクトへ連絡しないでください。
