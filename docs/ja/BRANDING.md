# ブランド

[English](../BRANDING.md) | [日本語](BRANDING.md)

Espanso GUIは独立したプロジェクトです。アプリケーションアイコンはこのリポジトリ専用に作成され、Espansoプロジェクトのロゴを再利用または模倣していません。

アイコンは、キー入力が変数braceを含む構造化templateへ展開される様子を表します。source assetは`icons/`にあります。

- `icon.png`：Linux packagingとapplication windowで使用する1024×1024のmaster
- `icon.icns`：PNG masterからlosslessに生成したmacOS application icon
- `icon.ico`：複数resolutionを含むWindows application icon

アイコンはアプリケーションと同じMIT Licenseで配布されます。「Espanso」は設定互換性を示すために説明的に使用し、商標はそれぞれの権利者に帰属します。
